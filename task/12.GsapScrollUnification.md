# Задача 12 — Унификация scroll-подписок в GsapProvider

Объединение размазанной логики scroll-обработки в единый механизм
`registerScrollTrigger` внутри GsapProvider. Удаление `GsapLayoutBridge` и
`useRegisterHomeSpacer`.

---

## 0. Зафиксированные решения

| #   | Решение                                                                                                       |
| --- | ------------------------------------------------------------------------------------------------------------- |
| D1  | **`GsapLayoutBridge` удаляется полностью.** Его функции поглощаются `registerScrollTrigger`.                  |
| D2  | **`useRegisterHomeSpacer` удаляется.** Логика встраивается в `GsapProvider.registerScrollTrigger`.            |
| D3  | **Progress транслируется через gsapBus.** Канал `scroll:progress` вместо ref-каналов.                         |
| D4  | **`registerScrollTrigger(el)` — метод GsapProvider.** Страница передаёт HTMLElement через хук/контекст.       |
| D5  | **ScrollTrigger один.** Всё (progress, boundary, mobile-pin) внутри одного `onUpdate`.                        |
| D6  | **`GsapProvider` экспортирует `useRegisterScrollTrigger()`** — хук, возвращающий `registerScrollTrigger(el)`. |

## 2. Целевая архитектура

```
GsapProvider
  │
  ├─ gsapBus (60fps)
  │    ├─ channel: 'scroll:frame' → { y, delta, time, direction }  (raw scroll)
  │    ├─ channel: 'frame' → { y, delta, time, direction }          (алиас)
  │    └─ channel: 'scroll:progress' → { progress, direction }     (scrub 0..1)
  │
  ├─ useRegisterScrollTrigger() → registerScrollTrigger(el)
  │    │
  │    └─ ScrollTrigger.create({
  │         trigger: el,
  │         start: 'top top',
  │         end: 'bottom top',
  │         scrub: true,
  │         onUpdate: (self) => {
  │           // 1. Progress → bus
  │           bus.emit('scroll:progress', { progress: self.progress, direction: self.direction })
  │           // 2. Boundary → engine
  │           if (progress <= 0.0001 && lastBoundary !== 'top')  send(REACH_TOP)
  │           if (progress >= 0.9999 && lastBoundary !== 'bottom') send(REACH_BOTTOM)
  │         }
  │       })
  │
  └─ children

Подписчики progress:
  ├─ useLayoutApplier: bus.on('scroll:progress', ...) → для scrub-анимации CSS vars (будущее)
  └─ useNavPosition (если воссоздастся): bus.on('scroll:progress', p => scrubTween.progress(p))
```

### Фаза 2: Создать `useRegisterScrollTrigger` в GsapProvider

**Файл:** `src/components/Layout/gsap/GsapProvider.tsx`

- [ ] Добавить `registerScrollTrigger(el: HTMLElement)` — создаёт ScrollTrigger, эмитит progress в bus, шлёт boundary события в engine
- [ ] Экспортировать `useRegisterScrollTrigger()` хук
- [ ] Использовать `useLayoutSend()` для boundary events
- [ ] Использовать `useGsapBus()` для progress

```ts
export function useRegisterScrollTrigger() {
  const bus = useGsapBus();
  const send = useLayoutSend();

  return useCallback(
    (el: HTMLElement): (() => void) => {
      let lastBoundary: 'top' | 'mid' | 'bottom' = 'mid';

      const st = ScrollTrigger.create({
        trigger: el,
        start: 'top top',
        end: 'bottom top',
        scrub: true,
        invalidateOnRefresh: true,
        onUpdate: (self) => {
          // Progress → bus
          bus.emit('scroll:progress', {
            progress: self.progress,
            direction: self.direction as 1 | -1,
          });

          // Boundary → engine
          const EDGE_EPS = 0.0001;
          if (self.progress <= EDGE_EPS && lastBoundary !== 'top') {
            lastBoundary = 'top';
            send({ type: 'REACH_TOP' });
          } else if (
            self.progress >= 1 - EDGE_EPS &&
            lastBoundary !== 'bottom'
          ) {
            lastBoundary = 'bottom';
            send({ type: 'REACH_BOTTOM' });
          } else if (self.progress > EDGE_EPS && self.progress < 1 - EDGE_EPS) {
            lastBoundary = 'mid';
          }
        },
      });

      return () => st.kill();
    },
    [bus, send],
  );
}
```
