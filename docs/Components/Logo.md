# Logo

## Обзор

Анимированный компонент логотипа, используемый на IntroAnimation. Импортирует SVG (`anvil_md.svg`) через `?react` (SVGR) и анимирует его с помощью GSAP DrawSVGPlugin. Эффект "прожига": по контуру пути бежит раскалённое оранжевое свечение, за которым проявляется чёткая линия основного цвета. Получает колбэк `onRegisterTimeline` через `AnimationComponentProps`, создаёт свой внутренний таймлайн и регистрирует его.

## Последовательность анимации

| Шаг | Действие                                                                     | Длительность | Позиция в таймлайне |
| --- | ---------------------------------------------------------------------------- | ------------ | ------------------- |
| 1   | `.glow-path` (толстый, #ff6b35, feGaussianBlur) прорисовывается от 0 до 100% | 1.5s         | 0                   |
| 2   | `.main-path` (тонкий, currentColor) прорисовывается от 0 до 100%             | 1.2s         | 0.15                |
| 3   | `.glow-path` плавно исчезает — остаётся только чёткий контур                 | 0.5s         | 1.2                 |

Общая длительность: ~1.7s (зарегистрировано в родительском таймлайне на `0` через колбэк `onRegisterTimeline`).

## Архитектура

### Структура файлов

```
Logo/
├── Logo.tsx             # Компонент с GSAP-анимацией DrawSVG
├── Logo.module.css      # Scoped-стили контейнера и SVG
├── anvil_md.svg         # SVG с двумя путями и фильтром свечения
└── index.ts             # Бочёночный экспорт
```

### SVG-файл (anvil_md.svg)

SVG содержит два `<path>` с одинаковым `d` и `<filter>` для эффекта прожига:

| Класс        | Роль                         | Визуал                                                                               |
| ------------ | ---------------------------- | ------------------------------------------------------------------------------------ |
| `.glow-path` | Эффект раскалённого свечения | `stroke="#ff6b35"`, `stroke-width="3"`, `filter="url(#moltenGlow)"`, `opacity="0.7"` |
| `.main-path` | Основной контур логотипа     | `stroke="currentColor"`, `stroke-width="1.5"`, `fill="none"`                         |

Фильтр `#moltenGlow`:

- `feGaussianBlur stdDeviation="1.5"` — размытие для эффекта свечения
- `feMerge` — наложение размытия поверх исходной графики

Оба пути имеют `fill="none"`, так как DrawSVGPlugin анимирует только stroke.

### Импорт SVG

Логотип импортируется через механизм SVGR (настроен в `vite.config.ts` через `vite-plugin-svgr`):

```tsx
import LogoSvg from './anvil_md.svg?react';
```

SVG рендерится как React-компонент, а пути находятся через `querySelector` по классу внутри контейнера:

```tsx
const glowPath =
  containerRef.current.querySelector<SVGPathElement>('.glow-path');
const mainPath =
  containerRef.current.querySelector<SVGPathElement>('.main-path');
```

### Используемые GSAP-плагины

- `DrawSVGPlugin` — зарегистрирован в `initGsap.ts`
- `useGSAP` — зарегистрирован в `initGsap.ts`

### Молния (Molten Glow)

Две параллельные анимации `drawSVG`:

1. **Glow-путь** стартует на `0s`: DrawSVG от `0% 0%` до `0% 100%` за 1.5s с `power2.inOut`.
2. **Main-путь** стартует на `0.15s`: DrawSVG от `0% 0%` до `0% 100%` за 1.2s с `power2.inOut` (догоняет glow).
3. По завершении прорисовки (на `1.2s`) glow-путь затухает (`opacity: 0` за 0.5s), оставляя только основной контур.

Визуально: оранжевое свечение "прожигает" путь, за ним проявляется чистый контур логотипа, затем свечение гаснет.

### Размеры

- Контейнер: `120px × 120px` (центрирование через `flex`)
- SVG заполняет контейнер на 100% (className `styles.svg`)
- `viewBox` сохранён из исходного SVG: `0 0 32 32`
