# NotFoundPage

Страница 404 — отображается для любого несуществующего маршрута. Рендерится
через catch-all роут `path: '*'` в `routes.tsx`.

## Архитектура

```
pages/NotFoundPage/
├── NotFoundPage.tsx          # Компонент (main, h1, p, NavLink)
└── NotFoundPage.module.css   # Стили (CSS Modules)
```

## Структура компонента

- `<main>` — контейнер на всю высоту viewport, flex-центрирование
- `<h1>` — код ошибки `404`, жирный шрифт через `--text-h`
- `<p>` — сообщение «Страница не найдена», цвет `--text`
- `<NavLink to="/">` — кнопка-ссылка «На главную» с accent-стилями

## Стили

Mobile-first, без медиа-запросов (desktop-вёрстка будет добавлена позже).
Используются семантические переменные проекта и design-tokens.

## Ключевые решения

- **Eager импорт** в `routes.tsx` — страница 404 не lazy, так как она требуется
  мгновенно при любом несуществующем пути
- **`NavLink` вместо `<a>`** — идиоматичная навигация react-router без
  перезагрузки страницы
- **Отсутствие `label` в `RouteConfig`** — catch-all роут не участвует в
  навигации и не попадает в `navItems` (фильтруется по `path !== '*'`)
