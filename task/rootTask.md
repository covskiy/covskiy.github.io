# Задача

Архитектура и документация React SPA для GitHub Pages

## Цель

Спроектировать структуру проекта, описать архитектурные решения и подготовить документацию.
НЕ генерируй реализацию компонентов или код анимаций на этом этапе. Только архитектура, структура файлов и конфигурационные файлы.

## Контекст

- Тип приложения: React SPA сайт-визитка
- Хостинг: GitHub Pages (статический экспорт)

## Технические требования

- Язык: TypeScript
- Сборщик: Vite
- Роутинг:
  - React Router v7+, используй BrowserRouter
  - Роуты должны быть отделены в отдельный файл
  - кастомный `404.html` fallback не нужен
- Анимации: GSAP 3+
- Стили: CSS Modules (с головным файлом - Типографикой)
- State management: не требуется
- Линтинг/форматирование: ESLint + Prettier (стандартные конфиги)
- Тесты: на этом этапе не требуются

## Поведенческие требования

1. При загрузке показывается intro-анимация на GSAP, после завершения плавно отображается основной контент.
2. На всех страницах присутствует фиксированный вертикальный navbar со списком услуг.
3. Клик по пункту навигации открывает соответствующий route без перезагрузки страницы.
4. Анимации должны корректно очищаться при смене роутов (kill/revert), чтобы не было утечек памяти и конфликтов.
5. Поддержка мобильных устройств: на экранах < 768px вертикальный navbar трансформируется в бургер-меню.

## Ограничения и особенности хостинга

- Все пути должны быть статическими.

## Требуемый вывод

1. 📄 `ARCHITECTURE.md` с разделами:
   - Дерево папок и файлов проекта в формате `tree`
   - Общая схема потоков данных и навигации
   - Стратегия роутинга и защита от багов на GitHub Pages
   - Стратегия стилизации и переиспользования компонентов
   - План code-splitting / lazy loading роутов

## Формат ответа

- Только markdown
- Сначала дерево файлов, затем документация, затем конфиги
- Комментарии в коде только там, где это влияет на архитектурное решение
