# Задача: правка CSS

## Контекст

В проекте не все CSS файлы выдерживают проверки Stylelint линтером.

## Задача

Запусти из package.json таску с линтером(npm run stylelint), и исправь ошибки им подсвеченные.
Для актуализации правил линтера используй mcp context7

## Прием задачи

Запусти из package.json таску с линтером(npm run stylelint), информации об ошибках не должно быть.
