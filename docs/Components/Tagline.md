# Tagline

## Обзор

Анимированный компонент теглайна, используемый на SplashPage. Воспроизводит анимацию печати на клавиатуре, за которой следует появление двух строк текста. Получает колбэк `onRegisterTimeline` через `AnimationComponentProps`, создаёт свой внутренний таймлайн и регистрирует его.

## Последовательность анимации

| Шаг | Действие                                                         | Длительность | Позиция в таймлайне |
| --- | ---------------------------------------------------------------- | ------------ | ------------------- |
| 1   | Клавиатура влетает сверху (`y: -120% → 0%`), проявляется         | 0.5s         | 0                   |
| 2.1 | Подсветка клавиши **C** (`fill`, `opacity`, `scale: 1.2`)        | 0.3s         | 0.9                 |
| 2.2 | Подсветка клавиши **O**                                          | 0.3s         | 1.09                |
| 2.3 | Подсветка клавиши **V**                                          | 0.3s         | 1.45                |
| 2.4 | Подсветка клавиши **S**                                          | 0.3s         | 1.77                |
| 2.5 | Подсветка клавиши **K**                                          | 0.3s         | 2.1                 |
| 2.6 | Подсветка клавиши **I**                                          | 0.3s         | 2.35                |
| 2.7 | Подсветка клавиши **Y**                                          | 0.3s         | 2.6                 |
| 2.8 | Подсветка клавиши **Enter**                                      | 0.3s         | 3.0                 |
| 3   | Клавиатура уезжает вниз за контейнер (`y: 0% → 120%`), исчезает  | 0.4s         | `>0`                |
| 4   | Две строки текста через SplitText: `y: -20 → 0`, `back.out(1.7)` | 0.6s + 0.15s | `>0`                |

Позиции подсветки клавиш — **абсолютные** на собственном таймлайне Tagline; на master-таймлайне смещены на `master.TAGLINE = 1.0`.

Общая длительность: ~5.0s на собственном таймлайне (≈6.0s на master-таймлайне). Регистрируется в родительском таймлайне на позиции `1.0` через колбэк `onRegisterTimeline`.

## Синхронизация с LogoText

Каждая клавиша в Tagline подсвечивается в тот же момент, когда соответствующая буква появляется в `LogoText`. Источник истины — `src/pages/SplashPage/splashChoreography.ts`:

- `tagline.keyOffsets` — позиции подсветки клавиш (Tagline-local секунды)
- `logoText.<X>.phaseDash.start` (для O–Y) и `logoText.C.phaseLetter.start` — моменты появления букв на master-таймлайне

| Клавиша | `tagline.keyOffsets` (Tagline-local) | Master-время | Соответствующая буква | LogoText-метрика      |
| ------- | ------------------------------------ | ------------ | --------------------- | --------------------- |
| C       | 0.9                                  | 1.9          | C                     | `C.phaseLetter.start` |
| O       | 1.09                                 | 2.09         | O                     | `O.phaseDash.start`   |
| V       | 1.45                                 | 2.45         | V                     | `V.phaseDash.start`   |
| S       | 1.77                                 | 2.77         | S                     | `S.phaseDash.start`   |
| K       | 2.1                                  | 3.1          | K                     | `K.phaseDash.start`   |
| I       | 2.35                                 | 3.35         | I                     | `I.phaseDash.start`   |
| Y       | 2.6                                  | 3.6          | Y                     | `Y.phaseDash.start`   |
| ENTER   | 3.0                                  | 4.0          | —                     | —                     |

`keyOffsets` вычисляются как `master.time - master.TAGLINE` (т.е. `master - 1.0`). Любое изменение тайминга появления букв в LogoText требует зеркального обновления `keyOffsets` для сохранения синхронизации.

## Архитектура

### Структура файлов

```
Tagline/
├── Tagline.tsx         # Компонент с GSAP таймлайном
├── Tagline.module.css  # Scoped-стили + :global селекторы SVG-клавиш
├── keyboard.svg        # SVG клавиатура с 8 путями клавиш
└── index.ts            # Бочёночный экспорт
```

### Клавиши SVG-клавиатуры

SVG содержит пути с сохранёнными именами классов (не обрабатываются CSS Modules):

| Класс SVG    | Клавиша |
| ------------ | ------- |
| `.key_c`     | C       |
| `.key_o`     | O       |
| `.key_v`     | V       |
| `.key_s`     | S       |
| `.key_k`     | K       |
| `.key_i`     | I       |
| `.key_y`     | Y       |
| `.key_enter` | ↵       |

Эти классы таргетятся GSAP-селекторами внутри scoped-контекста `useGSAP`. Стилизация выполняется через `:global()` в CSS Module, так как SVG-классы не трансформируются с хешами.

### Мапа клавиш в коде

В `Tagline.tsx` определена константа `KEY_MAP` — массив пар `{ selector, at }`, где `at` берётся из `SPLASH_CHOREOGRAPHY.tagline.keyOffsets`. Цикл `forEach` создаёт `tl.to(selector, { fill, opacity, scale }, at)` для каждой клавиши с абсолютной позицией. Это гарантирует, что каждая клавиша подсвечивается точно в нужный момент, без накопления ошибок от цепочки относительных позиций.

### Использование SplitText

- SplitText зарегистрирован в `src/utils/initGsap.ts`
- Создаётся **до** запуска внутреннего таймлайна (внутри `useGSAP`)
- Строки сразу скрываются через `gsap.set(split.lines, { y: -20, opacity: 0 })`
- Анимируются внутри таймлайна через `tl.fromTo(split.lines, ...)`, что синхронизирует их с playhead
- Контейнер использует `<div>` вместо `<p>` для избежания невалидной вложенности DOM (SplitText по умолчанию оборачивает строки в `div`)

### Обрезка контейнера

Элемент `.container` использует `overflow: hidden` и явную `height` для обрезки движения клавиатуры. Клавиатура начинается над видимой областью контейнера и уезжает за её нижнюю границу.

### Mobile-first стили

Базовые стили рассчитаны на мобильные устройства (phone, ≤480px):

- `.container` — `max-width: min(90vw, 360px)`, `height: 10rem` (2:1 SVG помещается в 320px viewport), `flex-shrink: 0` (защита от сжатия во flex-контейнере SplashPage)
- `.keyboard` — `display: flex; justify-content: center; align-items: center;`; SVG внутри — `width: 100%; height: 100%; max-width: 24rem; object-fit: contain` (сохраняет пропорции)
- `.text` — `font-size: 1.25rem`, `font-weight: 500`, `text-align: center`; позиционируется `position: absolute; top: 0` в верхней части контейнера, чтобы визуально прилегать к Logo (gap 2rem от SplashPage = 32px)
- Отступы по бокам — `padding: 0 1rem` для безопасной зоны от края экрана

Брейкпоинты для планшетов/десктопов пока не заданы — будут добавлены отдельной задачей.

### Расположение клавиатуры и текста

Клавиатура (`<div class="keyboard">`) и текст (`<div class="text">`) находятся в одном контейнере. Клавиатура занимает `position: static` (нормальный поток), текст — `position: absolute; top: 0` (поверх клавиатуры). Это позволяет:

1. Клавиатура анимируется в нормальном потоке (`y: -120% → 0% → 120%`)
2. Текст появляется в верхней части контейнера, где визуально ближе к Logo
3. После улёта клавиатуры вниз остаётся только текст (контейнер сохраняет высоту 10rem для стабильности layout)

### Используемые GSAP-плагины

- `SplitText` — зарегистрирован в `initGsap.ts`
- `useGSAP` — зарегистрирован в `initGsap.ts`

### Цвета клавиш

- Основной зелёный: `#04bf8a` (соответствует токену `--color-primary-500`)
- Клавиши стартуют прозрачными (`opacity: 0` через CSS)
- Анимируются до `opacity: 1` и `fill: #04bf8a`
