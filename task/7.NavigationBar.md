# Техническое задание: Multi-State Navigation Bar

## 1. Описание задачи

Реализовать многофункциональную навигационную панель (NavigationBar) для адаптивного SPA-сайта с тремя состояниями отображения:

- **Fullscreen**: полноэкранная навигация (только на `/home` в начале страницы)
- **standard**: вертикальная панель со списком страниц (25% viewport width, Tablet/Desktop)
- **Slim**: компактная полоска с иконками (~80px, Mobile/Tablet)

Навбар должен автоматически переходить между состояниями через ScrollTrigger при скролле и поддерживать ручное переключение через управляющий элемент (burger/arrow).

---

## 2. Архитектурные решения

### 2.1. Размещение компонентов

- **NavigationBar** располагается на верхнем уровне лейаута (внутри `<App />`, над `<Routes>`), монтируется один раз и всегда присутствует в DOM
- **Spacer** (blank filler 100vh) создается строго внутри `HomePage` как первый элемент для обеспечения физической длины скролла
- **LandingSections** содержит основной контент лендинга

### 2.2. Производительность и State-менеджмент

- **ЗАПРЕЩЕНО** передавать прогресс скролла через React State (Zustand/Redux/Context)
- **ОБЯЗАТЕЛЬНО** использовать прямую манипуляцию DOM через GSAP с `scrollTrigger` и `scrub`
- Все GSAP-твины регистрируются внутри хука `useGSAP` из `@gsap/react` для автоматической очистки при unmount

### 2.3. Управление состояниями

- Использовать CSS-классы: `.navbar-fullscreen`, `.navbar-standard`, `.navbar-slim`
- GSAP управляет классами через `classList.add/remove` или напрямую изменяет CSS-свойства
- **Приоритет**: автоскролл > ручное переключение (принудительное разворачивание при достижении верха страницы на `/home`)

### 2.4. Адаптивность

- Определение устройства через JavaScript (`window.matchMedia`) с listener на `resize`
- Breakpoints:
  - **Mobile**: `< 768px`
  - **Tablet**: `768px - 1024px`
  - **Desktop**: `> 1024px`

---

## 3. Состояния навбара

### 3.1. Fullscreen (Полноэкранный)

- **Размеры**: `width: 100vw`, `height: 100dvh`
- **Доступность**: только на `/home` в начальной позиции страницы
- **Layout**:
  - Mobile: `position: fixed`, `z-index: 1000`, прозрачный фон, контент под навбаром
  - Tablet/Desktop: `position: fixed` или `sticky`, контент сдвигается через `margin-left: 0`

### 3.2. standard (Вертикальная панель)

- **Размеры**: `width: 25vw`, `height: 100dvh`
- **Доступность**: Tablet/Desktop (результат скролла на `/home` или дефолтное состояние на других роутах)
- **Layout**: `position: fixed` или `sticky`, контент сдвигается через `margin-left: 25vw`
- **Содержимое**: вертикальный список ссылок на страницы сайта

### 3.3. Slim (Полоска с иконками)

- **Размеры**: `width: 80px`, `height: 100dvh`
- **Доступность**: Mobile (дефолтное), Tablet (при нехватке места)
- **Layout**: `position: fixed`, контент сдвигается через `margin-left: 80px`
- **Содержимое**: только иконки, без текста
- **Управляющий элемент**: burger (☰) для разворачивания

---

## 4. Поведение на устройствах

### 4.1. Mobile (`< 768px`)

#### Роут `/home`:

1. **Начальное состояние**: fullscreen (развернут на весь экран)
2. **Скролл вниз**:
   - ScrollTrigger с `scrub: true` привязан к spacer
   - Плавная анимация сворачивания в slim состояние
   - Элементы навбара сдвигаются к левому краю через `transform: translateX`
3. **Конечное состояние**: slim (полоска с иконками)
4. **Ручное переключение**: клик на управляющий элемент → toggle slim ↔ fullscreen
5. **Layout**: навбар `fixed` с `z-index` выше контента, прозрачный фон, контент не сдвигается

#### Роут `/another_route`:

1. **Начальное состояние**: slim
2. **Ручное переключение**: клик на управляющий элемент → toggle slim ↔ fullscreen
3. **Нет автоматического скролл-поведения**

### 4.2. Tablet (`768px - 1024px`)

#### Роут `/home`:

1. **Начальное состояние**: fullscreen
2. **Скролл вниз**:
   - ScrollTrigger с `scrub: true` привязан к spacer
   - Плавная анимация перехода fullscreen → standard
   - Контент лендинга появляется справа, `margin-left` плавно увеличивается от `0` до `25vw`
3. **Конечное состояние**: standard (вертикальная панель)
4. **Ручное переключение**:
   - Клик на управляющий элемент → toggle standard ↔ slim
   - Полноэкранное разворачивание невозможно (только через скролл к началу)
5. **Автоматический разворот**: при скролле к началу страницы → принудительный переход в fullscreen (приоритет над ручным slim состоянием)

#### Роут `/another_route`:

1. **Начальное состояние**: standard
2. **Ручное переключение**: клик на управляющий элемент → toggle standard ↔ slim
3. **Нет автоматического скролл-поведения**
4. **Полноэкранное разворачивание невозможно**

### 4.3. Desktop (`> 1024px`)

#### Роут `/home`:

1. **Начальное состояние**: fullscreen
2. **Скролл вниз**:
   - ScrollTrigger с `scrub: true` привязан к spacer
   - Плавная анимация перехода fullscreen → standard
   - Контент лендинга появляется справа, `margin-left` плавно увеличивается от `0` до `25vw`
3. **Конечное состояние**: standard (вертикальная панель)
4. **Нет ручного управления размерами** (отсутствует кнопка toggle)
5. **Автоматический разворот**: при скролле к началу страницы → принудительный переход в fullscreen

#### Роут `/another_route`:

1. **Начальное состояние**: standard
2. **Нет ручного управления размерами**
3. **Нет автоматического скролл-поведения**

### 5.2. Определение устройства (useDeviceType hook)

```tsx
import { useState, useEffect } from 'react';

type DeviceType = 'mobile' | 'tablet' | 'desktop';

export function useDeviceType(): DeviceType {
  const [deviceType, setDeviceType] = useState<DeviceType>('desktop');

  useEffect(() => {
    const checkDeviceType = () => {
      const width = window.innerWidth;
      if (width < 768) {
        setDeviceType('mobile');
      } else if (width >= 768 && width < 1024) {
        setDeviceType('tablet');
      } else {
        setDeviceType('desktop');
      }
    };

    checkDeviceType();

    const mediaQuery = window.matchMedia(
      '(min-width: 768px), (min-width: 1024px)',
    );
    mediaQuery.addEventListener('change', checkDeviceType);

    return () => mediaQuery.removeEventListener('change', checkDeviceType);
  }, []);

  return deviceType;
}
```

### 5.3. NavigationBar.tsx (Основной компонент)

```tsx
import { useState, useEffect } from 'react';
import { useGSAP } from '@gsap/react';
import gsap from 'gsap';
import { useLocation } from 'react-router-dom';
import { useDeviceType } from './useDeviceType';

export default function NavigationBar() {
  const location = useLocation();
  const deviceType = useDeviceType();
  const [currentState, setCurrentState] = useState<
    'fullscreen' | 'standard' | 'slim'
  >('fullscreen');

  const isHome = location.pathname === '/' || location.pathname === '/home';

  // Обработка смены роута
  useGSAP(
    () => {
      if (isHome) {
        // При переходе на /home сбрасываем в fullscreen
        setCurrentState('fullscreen');
        gsap.to('.navbar-wrapper', {
          className: '+=navbar-fullscreen',
          duration: 0.6,
          ease: 'power2.inOut',
        });
      } else {
        // На других роутах: mobile → slim, tablet/desktop → standard
        const targetState = deviceType === 'mobile' ? 'slim' : 'standard';
        setCurrentState(targetState);
        gsap.to('.navbar-wrapper', {
          className: `+=navbar-${targetState}`,
          duration: 0.6,
          ease: 'power2.inOut',
          overwrite: 'auto',
        });
      }
    },
    { dependencies: [location.pathname, deviceType] },
  );

  // Ручное переключение состояний
  const handleToggle = () => {
    let nextState: 'fullscreen' | 'standard' | 'slim';

    if (deviceType === 'mobile') {
      nextState = currentState === 'slim' ? 'fullscreen' : 'slim';
    } else if (deviceType === 'tablet') {
      nextState = currentState === 'slim' ? 'standard' : 'slim';
    } else {
      // Desktop: нет toggle
      return;
    }

    setCurrentState(nextState);
    gsap.to('.navbar-wrapper', {
      className: `+=navbar-${nextState}`,
      duration: 0.6,
      ease: 'power2.inOut',
      overwrite: 'auto',
    });
  };

  // Обновление margin-left контента
  useEffect(() => {
    const contentWrapper = document.querySelector('.content-wrapper');
    if (!contentWrapper) return;

    contentWrapper.classList.remove(
      'navbar-fullscreen-active',
      'navbar-standard-active',
      'navbar-slim-active',
    );

    if (currentState === 'standard') {
      contentWrapper.classList.add('navbar-standard-active');
    } else if (currentState === 'slim') {
      contentWrapper.classList.add('navbar-slim-active');
    }
  }, [currentState]);

  return (
    <nav className="navbar-wrapper navbar-fullscreen">
      {/* Управляющий элемент (только для mobile/tablet) */}
      {deviceType !== 'desktop' && (
        <button
          className="navbar-toggle-btn"
          onClick={handleToggle}
          aria-label="Toggle navigation"
        >
          {currentState === 'slim' ? '☰' : '←'}
        </button>
      )}

      {/* Контент навбара */}
      <div className="navbar-content">
        {/* Глобальная навигация */}
        <div className="global-nav">
          <a href="/" className="nav-link">
            Home
          </a>
          <a href="/about" className="nav-link">
            About
          </a>
          <a href="/contact" className="nav-link">
            Contact
          </a>
        </div>
      </div>
    </nav>
  );
}
```

### 5.4. HomePage.tsx (ScrollTrigger логика)

```tsx
import { useRef } from 'react';
import { useGSAP } from '@gsap/react';
import gsap from 'gsap';
import { ScrollTrigger } from 'gsap/ScrollTrigger';
import { useDeviceType } from './useDeviceType';

gsap.registerPlugin(ScrollTrigger);

export default function HomePage() {
  const containerRef = useRef<HTMLDivElement>(null);
  const spacerRef = useRef<HTMLDivElement>(null);
  const deviceType = useDeviceType();

  useGSAP(
    () => {
      // Определяем целевое состояние в зависимости от устройства
      const targetState = deviceType === 'mobile' ? 'slim' : 'standard';
      const targetWidth = deviceType === 'mobile' ? '80px' : '25vw';
      const targetMargin =
        deviceType === 'mobile'
          ? '0px'
          : deviceType === 'tablet'
            ? '25vw'
            : '25vw';

      // Анимация навбара
      const navbarTween = gsap.to('.navbar-wrapper', {
        width: targetWidth,
        ease: 'none',
        scrollTrigger: {
          trigger: spacerRef.current,
          start: 'top top',
          end: 'bottom top',
          scrub: true,
          onUpdate: (self) => {
            // При достижении верха (progress = 0) принудительно разворачиваем в fullscreen
            if (self.progress === 0) {
              gsap.to('.navbar-wrapper', {
                className: '+=navbar-fullscreen',
                duration: 0.3,
                overwrite: 'auto',
              });
            }
          },
        },
      });

      // Анимация сдвига контента (только для tablet/desktop)
      if (deviceType !== 'mobile') {
        gsap.to('.content-wrapper', {
          marginLeft: targetMargin,
          ease: 'none',
          scrollTrigger: {
            trigger: spacerRef.current,
            start: 'top top',
            end: 'bottom top',
            scrub: true,
          },
        });
      }

      // Анимация сдвига элементов внутри навбара к левому краю
      gsap.to('.navbar-content', {
        x: '-50%',
        ease: 'none',
        scrollTrigger: {
          trigger: spacerRef.current,
          start: 'top top',
          end: '50% top',
          scrub: true,
        },
      });
    },
    { scope: containerRef, dependencies: [deviceType] },
  );

  return (
    <div ref={containerRef}>
      {/* Spacer для обеспечения длины скролла */}
      <div ref={spacerRef} className="home-spacer" />

      {/* Основной контент лендинга */}
      <div className="landing-sections">{/* Секции лендинга */}</div>
    </div>
  );
}
```

## 6. Жизненный цикл анимации (Workflow)

### 6.1. Mobile: `/home` → скролл → `/about`

1. **Заход на `/home`**: навбар fullscreen, контент под ним
2. **Скролл вниз**: ScrollTrigger сворачивает навбар в slim, контент остается на месте
3. **Переход на `/about`**:
   - `HomePage` unmount → ScrollTrigger умирает
   - `NavigationBar` видит смену роута
   - Навбар остается в slim (дефолтное состояние для mobile)

### 6.2. Tablet: `/home` → скролл → ручной toggle → скролл к началу

1. **Заход на `/home`**: навбар fullscreen, контент с `margin-left: 0`
2. **Скролл вниз**: ScrollTrigger переводит в standard, `margin-left: 25vw`
3. **Ручной toggle**: пользователь кликает → навбар slim, `margin-left: 80px`
4. **Скролл к началу**:
   - ScrollTrigger обнаруживает `progress = 0`
   - Принудительный переход в fullscreen (приоритет над slim)
   - `margin-left: 0`

### 6.3. Desktop: `/about` → переход на `/home`

1. **На `/about`**: навбар standard, `margin-left: 25vw`
2. **Переход на `/home`**:
   - `useLocation` фиксирует смену роута
   - `NavigationBar` сбрасывает состояние в fullscreen
   - `HomePage` монтируется, создает ScrollTrigger
   - При скролле вниз: плавный переход fullscreen → standard

## 7. Edge Cases и их обработка

### 7.1. Поворот планшета (Tablet ↔ Desktop)

- `useDeviceType` слушает `resize` событие
- При изменении breakpoint автоматически пересчитывается целевое состояние
- GSAP с `overwrite: 'auto'` перехватывает управление и плавно переводит в новое состояние

### 7.2. Быстрый скролл с прерыванием анимации

- `overwrite: 'auto'` во всех `gsap.to()` вызовах
- Гарантирует, что новый tween убивает предыдущие конфликты

### 7.3. Переход между роутами с прерванным ScrollTrigger

- `useGSAP` автоматически вызывает `context.revert()` при unmount
- `NavigationBar` через `useLocation` перехватывает управление и доводит анимацию до целевого состояния

### 7.4. Конфликт ручного и автоматического переключения

- Приоритет: ScrollTrigger (автоскролл) > ручное переключение
- При достижении верха страницы на `/home` принудительный переход в fullscreen через `onUpdate` callback
