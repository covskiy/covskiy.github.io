### 1.2 Почему это надо фиксировать

1. Правки в «кто владеет x» и skip-условиях ломают поведение **без единого
   красного теста** — регрессии уезжают в прод.
2. `endX` связывает `homeEndState` (машина) и `window.innerWidth` (браузер) —
   перерасчёт легко сломать.
3. `buildScrub` пересобирает твин **с сохранением прогресса** — тонкая
   логика, уже порождавшая кадровые глитчи (комментарий
   `useNavPosition.ts:45-48`).
4. `prevManualRef.current = manualNow` **обязан** идти **после** skip-guard.
5. Resync guard стоит **до** invalidate и подписки; тест фиксирует
   «подписки нет, инвалидации нет» в обеих ветках.
6. `lastProgressRef` в `useToggleVisibility` сохраняет прогресс при
   перезапуске эффекта — corner: back-navigation на `/home` уже на дне.

```ts
import type { LayoutMode } from './layoutMode';
import { getNavTransform } from './geometry';

export interface ScrubBuildDecision {
  shouldBuild: boolean;
  endX: number | null;
  prevProgress: number;
}

export function decideScrubBuild(opts: {
  isHome: boolean;
  homeEndState: LayoutMode;
  viewport: number;
  existingProgress: number;
}): ScrubBuildDecision {
  if (!opts.isHome) {
    return { shouldBuild: false, endX: null, prevProgress: 0 };
  }
  return {
    shouldBuild: true,
    endX: getNavTransform(opts.homeEndState, opts.viewport).navX,
    prevProgress: opts.existingProgress,
  };
}

export function shouldAnimateDiscrete(opts: {
  isHome: boolean;
  manualNow: boolean;
  prevManual: boolean;
}): boolean {
  return !(opts.isHome && !opts.manualNow && !opts.prevManual);
}

export function shouldResyncScrub(opts: {
  isHome: boolean;
  isManualToggle: boolean;
}): boolean {
  return opts.isHome && !opts.isManualToggle;
}

export function shouldHideToggle(opts: {
  progress: number;
  isManualToggle: boolean;
  edgeEps: number;
}): boolean {
  return !(opts.progress >= 1 - opts.edgeEps || opts.isManualToggle);
}
```

**1.3 Рефакторинг `useNavPosition.ts`** (behaviour-preserving):

- `buildScrub` → `decideScrubBuild({ isHome: snapshot.isHome, homeEndState, viewport: window.innerWidth, existingProgress: scrubTweenRef.current?.progress() ?? 0 })`:

- `useEffect` → ранний `return` если `!shouldResyncScrub({isHome, isManualToggle})`.

**1.4 Рефакторинг `useToggleVisibility.ts`** (behaviour-preserving):

- `apply` → `classList.toggle(styles.isHidden, shouldHideToggle({ progress: lastProgressRef.current, isManualToggle: opts.isManualToggle, edgeEps: EDGE_EPS }))`.

### Фаза 4 — `renderHookLite`

**`src/test/renderHookLite.tsx`** — новый (~30 строк):

```tsx
import { createRoot, type Root } from 'react-dom/client';
import { act } from 'react';
import { getUseGSAPCallback } from './setupGsapMock';

export interface RenderHookResult<TResult> {
  result: { current: TResult };
  rerender: (hookFn: () => TResult) => void;
  unmount: () => void;
}

export function renderHookLite<TResult>(
  hookFn: () => TResult,
  options?: {
    wrapper?: React.ComponentType<{ children: React.ReactNode }>;
    onMount?: (root: HTMLElement) => void;
  },
): RenderHookResult<TResult> {
  const container = document.createElement('div');
  document.body.appendChild(container);
  const result: { current: TResult } = { current: undefined as TResult };
  let root: Root | null = null;
  let currentHookFn = hookFn;
  let cleanup: (() => void) | undefined;
  const Wrapper = options?.wrapper ?? (({ children }) => <>{children}</>);

  function Probe() {
    result.current = currentHookFn();
    return null;
  }

  // Имитация useGSAP-семантики: перед повторным колбэком (смена deps) и при
  // unmount выполняем cleanup предыдущего вызова (unsubscribe + kill твинов),
  // чтобы engine.subscribe не копился между rerender-ами.
  function invokeUseGSAPCallback() {
    const cb = getUseGSAPCallback();
    if (!cb) return;
    cleanup?.();
    cleanup = cb(container, <T extends Function>(f: T) => f) ?? undefined;
  }

  act(() => {
    root = createRoot(container);
    root.render(
      <Wrapper>
        <Probe />
      </Wrapper>,
    );
  });
  options?.onMount?.(container);
  invokeUseGSAPCallback();

  return {
    result,
    rerender(next) {
      currentHookFn = next;
      act(() => {
        root!.render(
          <Wrapper>
            <Probe />
          </Wrapper>,
        );
      });
      invokeUseGSAPCallback();
    },
    unmount() {
      act(() => {
        cleanup?.();
        root!.unmount();
      });
      container.remove();
    },
  };
}
```
