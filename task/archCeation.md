# Задача

Создать начальный архитектурный шаблон проекта

## Контекст

В текущей директории создан npm проект, в который установленны все необходимые зависимости и начальная конфигурация config файлов. Содержание tsx файлов получено от default шаблона vite и не содержат бизнес логику.
При написании GSAP кода, использую context7 mcp сервер для получения актуальной документации.

## Задача
