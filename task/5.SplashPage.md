# 📘 Техническое задание: SplashPage (React 19 + GSAP 3.14+)

_Версия 2.0. Оптимизировано под StrictMode, React 19, `@gsap/react`, современные паттерны типизации и barrel-экспорты._

---

## 1. Цель

Реализовать анимированную интро-страницу (Splash Screen), последовательно анимирующую три ключевых элемента: **Логотип**, **Логотекст** и **Слоган**. Анимация управляется единым `gsap.core.Timeline`, создаваемым в родительском компоненте и передаваемым в дочерние через пропсы.

**Дополнительные возможности:**

- Пропуск анимации по кнопке
- Чекбокс _"Больше не показывать"_ с сохранением флага в `localStorage`
- Автоматический пропуск SplashPage при повторных визитах
- Отсутствие FOUC (Flash Of Unstyled Content) и корректная работа в `React.StrictMode`

## 5. Утилиты и хуки

### `pages/SplashPage/utils/splashStorage.ts`

```ts
import type { SplashStorageData } from '../../../types/splash.types';

const STORAGE_KEY = 'splash_never_show';

export const splashStorage = {
  getNeverShow: (): boolean => {
    try {
      const data = localStorage.getItem(STORAGE_KEY);
      return data ? (JSON.parse(data) as SplashStorageData).neverShow : false;
    } catch {
      return false;
    }
  },

  setNeverShow: (value: boolean): void => {
    const data: SplashStorageData = {
      neverShow: value,
      timestamp: value ? Date.now() : undefined,
    };
    localStorage.setItem(STORAGE_KEY, JSON.stringify(data));
  },

  clearFlag: (): void => localStorage.removeItem(STORAGE_KEY),
};
```

### `pages/SplashPage/hooks/useSplashSkip.ts`

```ts
import { useState, useEffect, useCallback } from 'react';
import type { gsap } from 'gsap';
import { splashStorage } from '../utils/splashStorage';

type UseSplashSkipProps = {
  timeline: gsap.core.Timeline | null;
  onSkip?: () => void;
  skipDelay?: number;
};

export function useSplashSkip({
  timeline,
  onSkip,
  skipDelay = 1000,
}: UseSplashSkipProps) {
  // Синхронная инициализация исключает лишний ре-рендер и FOUC
  const [neverShowAgain, setNeverShowAgain] = useState(() =>
    splashStorage.getNeverShow(),
  );
  const [showSkipButton, setShowSkipButton] = useState(false);

  useEffect(() => {
    if (!timeline) return;
    const timer = setTimeout(() => setShowSkipButton(true), skipDelay);
    return () => clearTimeout(timer);
  }, [timeline, skipDelay]);

  const handleSkip = useCallback(() => {
    if (!timeline) return;
    // Нативный метод GSAP: мгновенно применяет финальные стили и очищает очередь
    timeline.progress(1).kill();
    onSkip?.();
  }, [timeline, onSkip]);

  const handleNeverShowAgain = useCallback((value: boolean) => {
    setNeverShowAgain(value);
    splashStorage.setNeverShow(value);
  }, []);

  return {
    showSkipButton,
    neverShowAgain,
    handleSkip,
    handleNeverShowAgain,
    shouldBypass: neverShowAgain,
  };
}
```

## 6. Компоненты

_Все компоненты используют `useGSAP` из `@gsap/react`, что гарантирует безопасную работу в `StrictMode` и автоматическую очистку._

### `components/Logo/Logo.tsx`

```tsx
import { useRef } from 'react';
import { useGSAP } from '@gsap/react';
import gsap from 'gsap';
import type { AnimationComponentProps } from '../../types/splash.types';
import styles from './Logo.module.css';

export function Logo({ timeline }: AnimationComponentProps) {
  const ref = useRef<HTMLDivElement>(null);

  useGSAP(
    () => {
      if (!timeline || !ref.current) return;

      const tween = gsap.fromTo(
        ref.current,
        { opacity: 0, scale: 0.5, visibility: 'visible' },
        { opacity: 1, scale: 1, duration: 0.8, ease: 'back.out(1.2)' },
      );

      timeline.add(tween, 0);
    },
    { dependencies: [timeline], scope: ref },
  );

  return (
    <div ref={ref} className={styles.logo} style={{ visibility: 'hidden' }}>
      <div className={styles.logoPlaceholder}>LOGO</div>
    </div>
  );
}
```

_(Аналогично для `LogoText.tsx` и `Tagline.tsx`. Отличается только `gsap.fromTo` параметры и время в `timeline.add`)_

## 7. Страница SplashPage

### `pages/SplashPage/SplashPage.tsx`

```tsx
import { useRef, useCallback } from 'react';
import { useGSAP } from '@gsap/react';
import gsap from 'gsap';
import { Logo, LogoText, Tagline, SkipControls } from '../../components';
import { useSplashSkip } from './hooks';
import { splashStorage } from './utils';
import type { SplashPageProps } from '../../types/splash.types';
import styles from './SplashPage.module.css';

export function SplashPage({ onComplete, skipDelay = 1000 }: SplashPageProps) {
  const timelineRef = useRef<gsap.core.Timeline | null>(null);

  const {
    showSkipButton,
    neverShowAgain,
    handleSkip,
    handleNeverShowAgain,
    shouldBypass,
  } = useSplashSkip({
    timeline: timelineRef.current,
    onSkip: onComplete,
    skipDelay,
  });

  const handleComplete = useCallback(() => {
    timelineRef.current?.kill();
    onComplete?.();
  }, [onComplete]);

  // Timeline создается один раз, реагирует на `shouldBypass`
  useGSAP(
    () => {
      if (shouldBypass) return;

      timelineRef.current = gsap.timeline({ onComplete: handleComplete });
    },
    { dependencies: [shouldBypass, handleComplete] },
  );

  if (shouldBypass) return null;

  return (
    <div className={styles.splashContainer}>
      <Logo timeline={timelineRef.current} />
      <LogoText timeline={timelineRef.current} />
      <Tagline timeline={timelineRef.current} />

      {showSkipButton && (
        <SkipControls
          timeline={timelineRef.current}
          onNeverShowAgain={handleNeverShowAgain}
          neverShowAgain={neverShowAgain}
          onSkip={handleSkip}
        />
      )}
    </div>
  );
}
```

## 8. Использование в `App.tsx`

```tsx
import { useState } from 'react';
import { SplashPage } from './pages/SplashPage';
import { splashStorage } from './pages/SplashPage/utils';

export default function App() {
  // Синхронная инициализация предотвращает FOUC главного контента
  const [showSplash, setShowSplash] = useState(
    () => !splashStorage.getNeverShow(),
  );

  const handleSplashComplete = () => setShowSplash(false);

  return (
    <>
      {showSplash && (
        <SplashPage onComplete={handleSplashComplete} skipDelay={800} />
      )}

      <main style={{ display: showSplash ? 'none' : 'block' }}>
        <h1>Главное содержимое</h1>
        <p>Приложение загружено!</p>

        {import.meta.env.DEV && (
          <button
            onClick={() => {
              splashStorage.clearFlag();
              window.location.reload();
            }}
          >
            🔄 Сбросить настройки Splash (Dev)
          </button>
        )}
      </main>
    </>
  );
}
```

## 9. Последовательность анимации

| Время (сек) | Элемент  | Анимация                                                       |
| ----------- | -------- | -------------------------------------------------------------- |
| `0.0`       | Logo     | `scale: 0.5 → 1`, `opacity: 0 → 1`, `ease: back.out(1.2)`      |
| `0.5`       | LogoText | `y: 30 → 0`, `opacity: 0 → 1`, `ease: power2.out`              |
| `1.0`       | Tagline  | `filter: blur(10px) → 0`, `opacity: 0 → 1`, `ease: power1.out` |

## 10. Схема работы механизма пропуска

```
[Пользователь заходит на сайт]
         ↓
[Синхронная проверка localStorage]
         ↓
    ┌────┴────┐
    ↓         ↓
[Флаг true] [Флаг false]
    ↓         ↓
[null]      [Рендер SplashPage + создание GSAP Timeline]
                      ↓
              [Кнопка "Пропустить" через 800мс]
                    ↓
              ┌─────┴─────┐
              ↓           ↓
        [click → progress(1).kill()]  [Естественное завершение]
                    ↓
              [onComplete → setShowSplash(false)]
```

## 11. Требования к реализации

| №   | Требование                                                                            | Приоритет |
| --- | ------------------------------------------------------------------------------------- | --------- |
| 1   | Timeline создается **ТОЛЬКО** в `SplashPage` через `useGSAP`                          | High      |
| 2   | Дочерние компоненты получают `timeline` через props и вызывают `timeline.add()`       | High      |
| 3   | Исходные стили скрыты через `visibility: hidden`, GSAP переключает на `visible`       | High      |
| 4   | Типизация строгая, `gsap.core.Timeline` вместо устаревшего `GSAPTimeline`             | High      |
| 5   | Кнопка пропуска появляется через заданный интервал                                    | High      |
| 6   | Флаг `"neverShowAgain"` сохраняется в `localStorage` синхронно                        | High      |
| 7   | При повторном заходе `SplashPage` **не рендерится** в DOM                             | High      |
| 8   | Пропуск выполняется через `timeline.progress(1).kill()` (без `gsap.set`/`clearProps`) | High      |
| 9   | Используется `@gsap/react`, ручные `useEffect` с GSAP запрещены                       | High      |
| 10  | Barrel-экспорты (`index.ts`) во всех папках для чистых импортов                       | Medium    |
| 11  | Кнопка сброса флага доступна только через `import.meta.env.DEV`                       | Medium    |

## 12. Отладка (dev-режим)

Для удобства в `main.tsx` можно добавить глобальный доступ к утилите сброса:

```ts
// main.tsx
import { splashStorage } from './pages/SplashPage/utils';

if (import.meta.env.DEV) {
  (window as any).splashDebug = {
    reset: () => {
      splashStorage.clearFlag();
      window.location.reload();
    },
    forceShow: () => {
      splashStorage.setNeverShow(false);
      window.location.reload();
    },
    forceHide: () => {
      splashStorage.setNeverShow(true);
      window.location.reload();
    },
    status: () => console.log('📊 neverShow:', splashStorage.getNeverShow()),
  };
}
```
